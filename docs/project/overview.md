# Система определения спама

Сервис автоматически определяет является ли сообщение спамом  
и отмечает его как "спам".

Основные пользователи:  
- пользователь.

Основные функции:  
- классификация сообщений;  
- уведомление пользователя об обнаружении спам-сообщении.  

## Комплект документации
1. Описание проекта - Поможет пользователям понять, что из себя представляет проект и чем будет им полезен. 
2. Требования - Более детальное описание технических особенностей системы для разработчиков.
3. Архитектура системы - Визуализация системы помогает разработчикам лучше понять, как она устроена.
4. Документация API - Нужна разработчикам для понимания того, какие запросы можно отправлять на сервис, в каком формате приходят ответы.
