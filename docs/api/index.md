# API

API предоставляет доступ к функциям ИИ-сервиса.

## Основные операции

- `POST /classify` — классифицировать категорию сообщения;
- `GET /classify/{id}` — получить статус задачи;
- `GET /ping` — проверить доступность сервиса.

## Спецификация

Полное описание API находится в файле `openapi.yaml`.
