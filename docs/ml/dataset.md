# Data Sheet

## Общая информация

**Название датасета:**  
ruSpamModels/russian-spam-detection

**Источник:**  
https://huggingface.co/datasets/ruSpamModels/russian-spam-detection

**Назначение:**  
Датасет для бинарной классификации сообщений (спам / не спам)

## Состав данных

**Объём:**  
4 511 513 сообщений

**Тип данных:**  
Текст

**Основные поля / признаки:**  
message : str - сообщение  
label : int - номер класса (1 - спам, 0 - не спам)

## Получение данных
Не указано.

## Предобработка

Текст токенизируется перед подачей на вход LLM

## Ограничения

* данные только на русском языке
* в сообщениях много опечаток, орфографических ошибок и т.д.

## Использование в проекте

Этот датасет будет использоваться для обучения классификационной головы RuBERT модели.

- Страница модели на Hugging Face: https://huggingface.co/DeepPavlov/rubert-base-cased
