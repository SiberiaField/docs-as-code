## Предобработка

## Ограничения

* данные только на русском языке
* в новостях и википедии много опечаток, орфографических ошибок и т.д.

## Использование в проекте

Этот датасет использовался для обучения RuBert. Благодаря этому датасету в модели есть фундаментальные знания о русском языке, поэтому нам остаётся только дообучить его под нашу конкретную задачу - бинарную классификацию спама.
