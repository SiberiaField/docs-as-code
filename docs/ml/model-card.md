# Model Card

## Общая информация

**Название модели:**  
DeepPavlov/rubert-base-cased

**Источник:**  
https://huggingface.co/DeepPavlov/rubert-base-cased

**Автор / организация:**  
Команда DeepPavlov

**Задача модели:**  
Данная модель может решать множество задач на русском тексте, в частности, классифицировать его.

**Язык:**  
Русский, Английский

## Использование в проекте

RuBert будет использоваться для классификации сообщения пользователя-отправителя.  
Модель будет решать задачу бинарной классификации - спам / не спам.

## Входные данные

На вход модель получает токенизированный текст на русском языке.

## Выходные данные

Модель возвращает одно число в диапозоне от 0.0 до 1.0 - вероятность принадлежности сообщения к спаму.

## Метрики качества

Авторы тестировали модель на трёх задачах (ParaPhrase, Sentiment Analysis (классификация текста), Question Answering)  
после чего посчитали среднее-арифметическое по 5 запускам.

F1 = 87.73 ± 0.26; Accuracy = 84.99 ± 0.35.

## Ограничения

* основные данные для обучения были на Русском, Английском и Китайском языках
* модель работает только с текстом
* базовая модель обучена на большом объёме общего текста и требует дообучения

## Не рекомендуется использовать

RuBert основан на оригинальном Bert, который способен решать задачи на Английском, Китайском и других языках, но преимущественно на первых двух. После дообучения, RuBert показал эффективность на русском языке, однако знания о других языках стали хуже, поэтому не рекомендуется использовать его на текстах где русский не является основным языком.
