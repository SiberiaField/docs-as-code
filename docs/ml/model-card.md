# Model Card

## Общая информация

**Название модели:**  
DeepPavlov/rubert-base-cased с классификационной головой на бинарную классификацию

**Источник:**  
https://huggingface.co/DeepPavlov/rubert-base-cased - базовая модель без классификационной головы

**Автор / организация:**  
Команда DeepPavlov

**Задача модели:**  
Базовый RuBERT может решать множество задач на русском тексте, в частности, классифицировать его.

**Язык:**  
Русский, Английский

## Использование в проекте

К RuBERT будет добавлена классификационная голова, после чего модель будет дообучена решать задачу определения спама (бинарная классификация сообщения).

## Входные данные

На вход модель получает токенизированный текст на русском языке.

## Выходные данные

RuBERT с классификационной головой будет возвращать одно число в диапозоне от 0.0 до 1.0 - вероятность принадлежности сообщения к спаму.

## Метрики качества

Авторы тестировали модель на трёх задачах (ParaPhrase, Sentiment Analysis (классификация текста), Question Answering)  
после чего посчитали среднее-арифметическое по 5 запускам.

Их результаты:  
F1 = 87.73 ± 0.26; Accuracy = 84.99 ± 0.35.

Метрик по классификации спама нет.

## Ограничения

* основные данные для обучения базовго RuBERT были на русском, английском и китайском языках
* модель работает только с текстом
* базовая модель обучена на большом объёме общего текста и требует дообучения
* дообучение модели будет выполнено на сообщениях на русском языке

## Не рекомендуется использовать

RuBERT основан на оригинальном BERT, который способен решать задачи на Английском, Китайском и других языках, но преимущественно на первых двух. После дообучения, RuBert показал эффективность на русском языке, однако знания о других языках стали хуже, поэтому не рекомендуется использовать его на текстах где русский не является основным языком.  

RuBERT с классификационной головой дообучен на датасете с сообщениями на русском языке, поэтому не следует использовать его на сообщениях на других языках.
